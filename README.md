# Financial Freedom - Family Finance Tracker

Minimal Django + DRF backend scaffold with a `finance` app.

Setup (Windows, PowerShell):

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Next steps:
- Create superuser `python manage.py createsuperuser`
- Open http://127.0.0.1:8000/api/ for API endpoints

PIN authentication endpoint (returns token):

POST http://127.0.0.1:8000/api/auth/pin/
Body JSON: { "username": "suami", "pin_code": "1234" }

Response: { "token": "<token>", "user": { ... } }

Project structure:
- fftrack/ (Django project)
- finance/ (Django app: models, admin, api)

This scaffold was generated by assistant; implement frontend (React PWA) separately.
